# 🍔 Swiggy Sales Analysis Dashboard (Excel Project)

## 📌 Project Overview

This project analyzes **Swiggy food delivery sales data** using **Microsoft Excel** to uncover key business insights related to revenue, customer behavior, food preferences, and regional performance.

An interactive Excel dashboard was created to help stakeholders quickly understand:

* Overall revenue performance
* Monthly, weekly, and daily sales trends
* Veg vs Non-Veg sales contribution
* State-wise and city-wise performance
* Customer satisfaction through ratings

## 🎯 Problem Statement

To analyze Swiggy’s sales data and generate insights for:

* Overall revenue and order trends
* Food type contribution (Veg vs Non-Veg)
* Regional performance by states and cities
* Customer satisfaction through ratings
* Revenue variations across time (monthly, weekly, daily)

## 📈 Dashboard Insights

### 1. Monthly Sales Trend

* Sales fluctuate between **₹6.2M – ₹6.9M**
* Highest sales observed in **August & May**
* Slight dip during **February**

### 2. Daily Sales Trend

| Day       | Sales   |
| --------- | ------- |
| Sunday    | ₹ 7.64M |
| Monday    | ₹ 7.45M |
| Tuesday   | ₹ 7.36M |
| Wednesday | ₹ 7.54M |
| Thursday  | ₹ 7.66M |
| Friday    | ₹ 7.58M |
| Saturday  | ₹ 7.78M |

➡️ **Saturday** is the highest performing day.

---

### 3. Sales by Food Type

| Food Type   | Sales   | Contribution |
| ----------- | ------- | ------------ |
| **Non-Veg** | ₹ 33.3M | 63%          |
| **Veg**     | ₹ 19.7M | 37%          |

➡️ Non-Veg dominates overall revenue.

---

### 4. Sales by Quarter

| Quarter | Sales   | Avg Rating | Orders |
| ------- | ------- | ---------- | ------ |
| Q1      | ₹ 19.7M | 4.3        | 73.10K |
| Q2      | ₹ 19.9M | 4.3        | 74.16K |
| Q3      | ₹ 13.4M | 4.3        | 50.17K |

➡️ Q2 performed the best in terms of revenue.

---

### 5. Top 5 States by Sales

1. **Karnataka** – ₹ 5.46M
2. **Uttar Pradesh** – ₹ 3.12M
3. **Telangana** – ₹ 3.02M
4. **Maharashtra** – ₹ 3.02M
5. **Delhi** – ₹ 2.83M

---

### 6. Weekly Sales Trend

* Sales are consistent across weeks
* Peak observed around **Week 8**
* Stable demand throughout the year
